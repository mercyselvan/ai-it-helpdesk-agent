PASSWORD TROUBLESHOOTING

Problem: User forgot a password.

Steps:
1. Confirm which account or service requires the password.
2. Use the service's official password-reset process.
3. Follow the identity verification steps provided by the service.
4. Create a new password that is difficult to guess.
5. Do not share passwords with other people.
6. If the account belongs to an organization and self-service reset is unavailable, contact the organization's IT helpdesk.

Problem: Password is not being accepted.

Steps:
1. Check that Caps Lock is not enabled accidentally.
2. Make sure the correct account is being used.
3. Carefully re-enter the password.
4. If the password is forgotten, use the official password-reset procedure.
5. If the account becomes locked, contact the appropriate administrator or helpdesk.
